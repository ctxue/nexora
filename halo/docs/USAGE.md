# NEXORA HALO 使用指南

## 启动

双击 `nexora-halo.exe`。信息岛默认贴在屏幕顶部，鼠标靠近后展开。

右键单击系统托盘中的 NEXORA HALO 图标，从菜单可以：

- 打开设置
- 显示或隐藏“岛屿”
- 切换极简刘海
- 开关开机启动
- 查看关于信息
- 退出

## 页面

NEXORA HALO 保留四个页面：

1. 音乐
2. 文件口袋
3. 剪贴板
4. 邮箱

底部分页两侧的箭头、页码或鼠标滚轮可以切换页面。页面可在设置中隐藏和排序，但至少保留一个页面。

## 消息提醒

微信提醒根据任务栏闪动识别，不读取聊天正文。QQ 需要在 QQ 中开启 Windows 系统通知，并允许 NEXORA HALO 读取通知。

通知正文默认隐藏。开启预览后，验证码仍会遮罩。

## 文件与剪贴板

把文件拖到信息岛屿可以加入文件口袋。文件口袋只保存路径，不复制文件。从文件口袋移除条目不会删除原文件。

剪贴板历史默认可用，可在设置中关闭。密码管理器标记为敏感的内容不会采集。

## 邮箱

在设置 → 邮箱中添加账号。授权码或 App 专用密码保存在 Windows 凭据管理器。

Gmail 需要在 Google 账号中创建 App 专用密码；QQ、163、126 等邮箱需要先启用 IMAP 并生成授权码。

## 更新

设置 → 关于中可检查更新。更新包会校验 SHA-256，校验失败时不会替换当前程序。

## 数据

默认数据目录：

```text
%APPDATA%\NEXORA\Halo
```

卸载程序时用户数据默认保留。若要彻底删除账号记录，应先在设置中移除邮箱账号，再清理数据目录。
