# Changelog

## [Unreleased]

## [0.2.0] - 2026-11-08

- 产品更名为 **NEXORA ISLE · 岛屿**，可执行文件改为 `nexora-isle.exe`。
- 数据目录迁移到 `%APPDATA%\NEXORA\Isle`，兼容早期版本目录和邮件凭据。
- 新增图片查看弹窗、首尾循环切换和底部缩略图分页器。
- 图片页移除悬浮预览，只保留独立查看弹窗。
- 修复顶部任务栏或 Dock 抢占岛屿层级时通知按钮无法点击的问题。
- 剪贴板图片改为仅保存在运行时内存，统一列表、查看器和计数来源，并修复清空后固定图片仍残留的问题。
- 默认改为点击展开并保留悬停放大，可切换悬停展开；两种模式移出岛屿都立即收起。
- 重构岛屿布局编辑器、通知与邮箱设置；微信和 QQ 提醒默认开启，邮箱账号本地持久化并在启动后自动重连。
- 修复首次展开时标题、正文、按钮和分页器随宽度弹簧过冲而横向抖动的问题；内容轴从首帧固定，外形仍保留展开动画。
- 岛屿可见时持续维护置顶带首位，避免被全屏窗口或任务栏自带的 topmost 窗口覆盖。
- 图片右键菜单新增“另存为 PNG…”，列表与独立查看器均支持通过 Windows 原生对话框保存。
- 产品中文名统一为“岛屿”；重写源码注释并清理无引用资源与静态检查告警。
- 发布文件统一为 `NEXORA_ISLE_<版本>_x64_setup.exe` 与 `NEXORA_ISLE_<版本>_portable.zip`。

## [0.1.0] - 2026-11-07

### Added

- 独立的 NEXORA ISLE 产品工程与品牌资源。
- 刘海、胶囊、多皮肤、三边停靠和四页信息岛界面。
- 音乐与歌词、微信/QQ 提醒、文件口袋、剪贴板、IMAP 邮件和系统状态。
- NEXORA ISLE 专属数据目录、凭据命名空间、安装器和更新入口。
- 四页设置模型和旧版八页配置迁移。

### Removed

- 专注与番茄钟。
- 饮水记录与提醒。
- AI 额度账号、服务和界面。
- 日历、CalDAV、Exchange、ICS 导入和会议提醒。
- 原项目品牌、打赏入口、Logo 和更新仓库。
