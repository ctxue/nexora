# Changelog

## [Unreleased]

- 产品更名为 **NEXORA ISLE · 星屿**，可执行文件改为 `nexora-isle.exe`。
- 数据目录迁移到 `%APPDATA%\NEXORA\Isle`，兼容早期版本目录和邮件凭据。
- 新增图片查看弹窗、首尾循环切换和底部缩略图分页器。
- 发布文件统一为 `NEXORA_ISLE_<版本>_x64_setup.exe` 与 `NEXORA_ISLE_<版本>_portable.zip`。

## [0.1.0] - 2026-11-07

### Added

- 独立的 NEXORA ISLE 产品工程与品牌资源。
- 刘海、胶囊、多皮肤、三边停靠和四页信息岛界面。
- 音乐与歌词、微信/QQ 提醒、文件口袋、剪贴板、IMAP 邮件和系统状态。
- NEXORA ISLE 专属数据目录、凭据命名空间、安装器和更新入口。
- 四页设置模型和旧版八页配置迁移。

### Removed

- 专注与番茄钟。
- 饮水记录与提醒。
- AI 额度账号、服务和界面。
- 日历、CalDAV、Exchange、ICS 导入和会议提醒。
- 原项目品牌、打赏入口、Logo 和更新仓库。
