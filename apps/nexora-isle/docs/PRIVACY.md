# 隐私说明

## 本地数据

NEXORA ISLE 默认在以下目录保存设置、文件口袋路径、剪贴板历史和连接元数据：

```text
%APPDATA%\NEXORA\Isle
```

`NEXORA_ISLE_DATA_DIR` 可以覆盖该目录。

## 凭据

- 邮箱授权码保存在 Windows 凭据管理器。
- 需要独立加密缓存的会话使用 Windows DPAPI。
- 程序不把邮箱密码、授权码或 API 凭据写入普通设置文件。

## 邮件

邮件通过 IMAP 直接连接用户配置的邮箱服务。邮件正文只用于本机展示和验证码识别，不发送到 NEXORA 自建服务器。

## 消息通知

微信提醒只观察任务栏闪动状态，不读取联系人、聊天列表或聊天正文。

QQ 与其他应用通知来自 Windows 通知中心。通知正文默认隐藏，用户可以在设置中开启预览。

## 文件

文件口袋只保存文件路径，不复制或上传文件内容。剪贴板历史只保存在本机，并尽量过滤密码、私钥和常见 Token。

敏感内容过滤是启发式保护，不能覆盖所有格式。处理高敏感信息时建议关闭剪贴板历史。

## 网络

启用联网功能后，程序可能访问用户配置的 IMAP 邮箱服务器、歌词服务、受支持的播放器本地缓存，以及更新发布页和更新下载地址。

程序不包含 NEXORA 自建的邮件、通知或日历上传后台。
